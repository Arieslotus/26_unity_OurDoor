# OurDoor 联网功能交付说明

## 1. 联网与登录

- 多个 Unity PC 客户端可连接同一 Skynet 服务端。
- 客户端根据外部配置自动连接，并使用临时账号登录。
- 提供可随时打开或关闭的游戏内联网操作界面。

## 2. 房间与匹配

- 支持创建房间及使用房间码加入。
- 支持选择关卡和 Outer/Inner 身份。
- 支持指定关卡、任意关卡及身份偏好匹配。
- 两名玩家配对后进入同一关卡并获得互补身份。

## 3. 三关协作

- 第一、第二、第三关的关键协作事件均由服务端校验并同步。
- 支持双方按 Outer/Inner 身份完成不同的协作操作。
- 支持从第一关连续推进至第三关，并保持房间和身份。

## 4. 退出与清理

- 一名玩家退出后，另一名玩家收到通知并返回大厅。
- 服务端自动清理相关账号、房间和匹配状态。
- 仍在线的玩家可以继续创建房间、加入房间或匹配。

## 5. 局域网部署

- Unity 客户端、Skynet 服务端和管理工具可组装为统一发布包。
- 支持局域网主机的一键安装、启动、停止和重复启动复用。
- 主机游戏关闭后服务端可继续运行，其他客户端仍可联机。
