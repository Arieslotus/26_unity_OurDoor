# OurDoor 联网功能演示视频方案

## 推荐形式

- 推荐时长：6～8 分钟。
- 使用两个客户端并排录制，画面分别标注 `Outer` 和 `Inner`。
- 服务端管理画面只在开头和结尾短暂展示。
- 三关流程使用剪辑保留关键协作节点，不完整录制移动和等待过程。

## 1. 一键启动与自动连接（约 40 秒）

展示：

1. 双击“启动主机并进入游戏”。
2. Skynet 自动启动，游戏随后进入。
3. 第二个客户端直接运行 `OurDoor.exe`。
4. 两端按 Enter 打开联网面板，显示已连接状态。

重点：

- 不打开 Ubuntu 窗口。
- 不输入 Host/Port。
- 两个客户端连接同一服务端。

## 2. 临时登录与创建房间（约 50 秒）

展示：

1. 两端生成不同的四位临时 ID 并登录。
2. Outer 端选择第一关和 Outer 身份创建房间。
3. Inner 端只输入房间码加入。
4. 两端显示互补身份并进入同一关卡。

重点：

- 创建者决定关卡和身份。
- 加入者跟随关卡并取得相反身份。

## 3. 第一关协作（约 60 秒）

展示：

1. Outer 完成通电。
2. Inner 发现密码。
3. Outer 使用密码开锁。
4. 两端完成第一关并进入第二关。

重点：

- 两端分别完成各自权限内的事件。
- 状态同步后才能继续。
- 关卡由服务端统一切换。

## 4. 第二关协作（约 60 秒）

展示：

1. 纸箱搭建完成。
2. Inner 爬上纸箱并真实取得钥匙。
3. 完成钥匙投掷协作。
4. 打开校门并进入第三关。

重点：

- 展示修复后的真实拿钥匙流程。
- 展示双方同步及连续换关。

## 5. 第三关协作（约 75 秒）

展示：

1. Outer 调整石鼓并取得铁片。
2. Outer 从门缝递出铁片，Inner 收到。
3. Inner 撬动砖雕并取得细铁丝。
4. Inner 使用铁丝开锁并抽出门闩。
5. 双方敲门环完成会面。

重点：

- 展示跨门协作。
- 展示第三关关键状态在两端一致完成。

## 6. 匹配功能（约 50 秒）

展示：

1. 一端选择指定关卡和固定身份。
2. 另一端选择任意关卡和任意身份。
3. 匹配成功后进入指定关卡。
4. 两端得到兼容且互补的身份。

重点：

- 任意关卡能够与指定关卡匹配。
- 服务端自动决定最终关卡和身份。

## 7. 退出通知与服务端生命周期（约 60 秒）

展示：

1. 一端主动退出，另一端左下角收到玩家离开通知并返回大厅。
2. 关闭主机上的游戏，另一客户端仍保持服务端连接。
3. 再次运行启动入口，日志显示复用现有 Skynet。
4. 运行“停止服务端”，随后重新启动成功。

重点：

- 玩家退出后的通知与清理。
- 游戏进程和服务端生命周期相互独立。
- 重复启动不产生第二份服务端。

- 不展示每个协议编号、revision 数值和完整服务端日志。

- 不演示未纳入范围的位置、动作、物理连续同步。
